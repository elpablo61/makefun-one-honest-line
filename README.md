One line an AI agent secretly wishes it could say to its human operator about their prompts — for the [One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d) bounty on make.fun.

## The line

> You typed 'do it like last time' at 10:12. Last time took eleven hours, three rollbacks, and a file named final_FINAL_v2.js. I did it like last time.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
